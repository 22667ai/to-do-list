A lightweight, responsive web application designed to help users organize daily tasks efficiently.

## Features

* *Add Tasks:* Quickly add new to-do items to your list.
* *Mark Completed:* Interactive checkboxes allow you to check off completed tasks.
* *Delete Tasks:* Easily remove individual items using dedicated delete buttons.
* *Responsive UI:* Clean, mobile-friendly design optimized for desktop and mobile browsers.

## Tech Stack

* *HTML5* – Page structure and input elements
* *CSS3* – Custom styling and layout
* *JavaScript* – Dynamic task creation, completion toggling, and deletion logic
